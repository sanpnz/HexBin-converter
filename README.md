Написать утилиту на "чистом" (не ++) Си для конвертации файла ASCII HEX в
бинарное содержимое и наоборот. Например, входной HEX файл с содержимым
"30313220" преобразуется в выходной BIN файл с содержимым "012 ".

Имя входного файла и тип конвертации передается через параметр командной
строки. Результат должен сохраняться в выходной файл, имя которого
формируется из имени входного файла с добавлением расширения ".hex" или
".bin" в зависимости от его типа.

   Например:
   - вызов "conv.exe -a file-name.hex" конвертирует входной HEX файл в выходной
     бинарный файл с именем "file-name.hex.bin"
   - вызов "conv.exe -b file-name.bin" конвертирует входной бинарный файл в
    выходной файл в формате HEX с именем "file-name.bin.hex"

Утилита должна выводить свое описание и инструкцию по использованию при
получении параметра "-h", а также завершаться с сообщением об ошибке при
получении неизвестного параметра.

Исходный код утилиты должен компилироваться с помощью gcc без ошибок и
предупреждений под LINUX и Windows.
